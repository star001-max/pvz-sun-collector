# PvZ 自动拾取阳光脚本

一个基于图像识别的植物大战僵尸辅助脚本——自动检测并收集阳光，让你专注于策略布局。

---

## 功能特性

- **图像识别拾取** — 使用 pyautogui 匹配阳光贴图，自动定位并点击收集
- **排除卡片槽** — 只搜索草坪区域，不会误触顶部的植物卡片
- **瞬移点击** — 点击瞬间保存并恢复鼠标位置，用户几乎感觉不到鼠标被占用
- **追踪下落阳光** — 阳光下落过程中持续追踪位置，确保收集成功
- **即按即停** — 独立键盘监听线程，按 Shift 立刻暂停，鼠标马上恢复自由
- **多重安全出口** — Shift 暂停、Ctrl+Shift+Q 退出、FAILSAFE 角落停止、Ctrl+C 终止

---

## 环境要求

- Windows 系统（Win32 API 实现热键和瞬移点击）
- Python 3.7+
- pyautogui

```bash
pip install pyautogui
```

---

## 使用方法

1. 先启动植物大战僵尸游戏，进入任意关卡
2. 切到终端运行脚本：

```bash
python 自动拾取阳光.py
```

3. 脚本 3 秒后开始工作，回到游戏即可

## 快捷键

| 按键 | 功能 |
|------|------|
| `Shift` | 暂停 / 恢复 |
| `Ctrl + Shift + Q` | 紧急退出 |
| `Ctrl + C` | 终端退出 |
| 鼠标移到屏幕四角 | FAILSAFE 紧急停止 |

---

## 原理简述

| 模块 | 实现方式 |
|------|---------|
| 阳光检测 | pyautogui.locateOnScreen 彩色模板匹配，置信度 0.65 |
| 搜索区域 | 排除屏幕顶部 12%（卡片槽所在），只扫描草坪 |
| 点击方式 | SetCursorPos 瞬移 → mouseDown → 停留 40ms → mouseUp → 恢复原位 |
| 热键监听 | 后台线程每 20ms 通过 GetAsyncKeyState 轮询按键状态 |
| 暂停机制 | 全局 ENABLED 标志 + threading.Lock，所有操作循环检查 |

## 可调参数

脚本顶部常量可直接修改：

```python
EXCLUDE_TOP_RATIO = 0.12   # 排除顶部比例，误触卡片可调大（如 0.15）
confidence = 0.65          # 匹配置信度，找不到阳光可调低（如 0.6）
SEARCH_TOP                 # 排除的像素高度，自适应屏幕分辨率
```

---

## 注意事项

- 脚本依赖游戏自带的阳光贴图（`resources/graphics/Plants/Sun/`），请保持该目录完整
- 仅支持 Windows 系统（使用了 `ctypes.windll`）
- 游戏分辨率不同时，可能需要调整 `EXCLUDE_TOP_RATIO`
